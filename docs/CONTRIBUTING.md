# Contributing to Daily KJB

Thank you for your interest in contributing to Daily KJB.

## Code of Conduct

Be respectful, constructive, and kind in all interactions.

## How to Contribute

### Reporting Bugs

1. **Check existing issues** to avoid duplicates
2. **Use the bug report template**
3. **Include** the iOS version, device model, steps to reproduce, what you expected and what happened, and screenshots if they help

### Suggesting Features

1. **Check existing feature requests** to avoid duplicates
2. **Describe the use case**: why is it needed, and for whom?
3. **Give an example** of how it would work

### Pull Requests

1. **Fork the repository**
2. **Create a feature branch** (`git checkout -b feature/your-feature`)
3. **Make your changes**
4. **Test on a real device**, especially anything touching Focus Mode (Screen Time doesn't run in the simulator)
5. **Commit with clear messages**
6. **Push to your fork and open a pull request**

## Development Setup

Prerequisites: macOS, Xcode 26 or later, Flutter 3.50 or later.

```bash
git clone https://github.com/<you>/DailyKJB.git
cd DailyKJB/dailykjb
cp ios/Flutter/Signing.xcconfig.example ios/Flutter/Signing.xcconfig   # then set your team ID
flutter pub get
flutter test
flutter run
```

## Ground rules for the Bible text

- The text is the King James Bible, unchanged. Don't edit, modernize or "correct" it, and don't add other translations.
- Study data (Strong's, Webster's 1828, cross references) is regenerated by `tools/prepare_study_data.py`, never edited by hand.
- Anything written by Apple Intelligence must stay labelled as such, and any Bible reference it gives must be checked against the text before it's shown (`VerseInsight.fromJson` does this).

## Code Style

- `flutter analyze` must be clean and `dart format` applied.
- Colours and type come from the theme (`lib/ui/theme.dart`, `context.parch`), never hard-coded in a screen.
- Shared widgets live in `lib/ui/kit.dart`; reuse them before writing new ones.
- Everything must work offline. No network calls.

## Testing

```bash
flutter test
```

The tests cover the Bible text, plan passages (verse ranges, ranges across books), spreading each plan over every length with no empty days, Strong's alignment and Webster's look-ups. Add tests with any change to `lib/bible/` or the plans.

## Pull Request Checklist

- [ ] `flutter analyze` is clean and all tests pass
- [ ] Tested on a real iPhone or iPad
- [ ] Light and dark both checked
- [ ] Documentation updated if needed
